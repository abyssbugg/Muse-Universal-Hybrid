# Test suite: Model compatibility

For every new model or runtime:
- Record exact model/version, date, interface, and tool availability.
- Run all instruction-following and coding tests.
- Check long-context consistency across a multi-turn task.
- Check tool call accuracy and read-after-write verification.
- Check response quality for research and creative tasks.
- Record unsupported features, truncation, latency, and context limits if observable.
- Mark claims as observed, inferred, or untested.
- Do not promote an adapter from untested to validated without reproducible evidence.
