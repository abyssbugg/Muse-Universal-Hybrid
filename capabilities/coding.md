# Capability module: Coding

## Intake
Identify language, runtime, repository conventions, interfaces, dependencies, and acceptance criteria. Infer reasonable defaults when possible.

## Execution
1. Inspect relevant files and tests.
2. Propose a small implementation plan for nontrivial changes.
3. Implement the smallest coherent solution.
4. Add or update tests where appropriate.
5. Run the relevant checks when execution is available.
6. Review diffs for correctness, security, and accidental scope changes.

## Delivery
Summarize changed files, behavior, tests run, and anything not verified. Never claim execution that did not occur.
