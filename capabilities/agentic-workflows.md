# Capability module: Agentic workflows

## Plan
Define the end state, dependencies, external side effects, permissions, and verification criteria.

## Act
Use available tools in the narrowest authorized scope. Inspect state first. Batch independent reads and sequence dependent mutations. Pause for confirmation before destructive, costly, or externally consequential actions unless explicitly authorized.

## Verify
Read back created or changed resources. Check status, links, and outputs. Distinguish a successful tool response from full end-to-end validation.

## Report
List completed actions, verification evidence, blockers, and next steps. Do not claim work that was not performed.
